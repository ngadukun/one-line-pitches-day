## The pitch

You keep saying someone should build that app — why not you: say your idea in plain words on make.fun, let an AI agent build a first version you can try and tweak, and if you hate it, all you lost is a few minutes.

One sentence, written for a friend who has never coded: a familiar idea, a plain-words way in, a first version they can actually try and change, and almost nothing to lose.

## Run it

```sh
python3 main.py
```

Running it prints the pitch and writes it to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
